# Plan 14-01: Reports and Export

## Objective

Add CSV download of all submission data and per-candidate print-to-PDF via browser print dialog to AdminPanel.

## Tasks

### Task 1: Build CSV Export Utility
Create `src/utils/exportCsv.js` with two exports:
- `escapeCsvField(value)` — RFC 4180 field escaping (wrap in quotes if contains comma/quote/newline, double any internal quotes)
- `downloadCsv(rows, filename)` — takes array of objects, builds CSV blob with header row from `Object.keys(rows[0])`, triggers browser download via `URL.createObjectURL` + anchor click

Use `\r\n` line endings for Excel compatibility.

### Task 2: Add Download CSV Button
Add a "Download CSV" button to AdminPanel.jsx in the header bar between Refresh and Back buttons. On click:
1. Build a flat CSV row per candidate from the `candidates` array: name, email, status, totalScore, gradeBand, zone1Score, zone2Score, zone3Score, zone4SocScore, tabSwitches, submissionDate
2. Call `downloadCsv(rows, "flagmail-submissions.csv")`

Disable button while `loading` is true. Use same button style as Refresh/Back.

### Task 3: Add Print Report Button
Add a "Print Report" button to AnswerSheet.jsx next to the Back button. On click, call `window.print()`. Add `className="print-target"` to the outer wrapper div so print CSS can scope visibility.

### Task 4: Add Print CSS
Add `@media print` block to `src/index.css`:
- Hide `body > *` except elements with `.print-target` or `.print-target *`
- Force white background, black text, remove shadows/backdrop-filter on `.print-target`
- Add `.print-page-break { page-break-after: always; }` utility
- Set `@page { margin: 12mm; }`

## Success Criteria

1. Clicking "Download CSV" in AdminPanel triggers a file download with all candidate records — name, email, scores per dimension, grade band, submission date, proctoring count — as properly escaped CSV (verified by opening in Excel/Sheets)
2. Clicking "Print Report" on AnswerSheet opens browser print dialog with print-optimized layout — candidate name, scores, and answer text visible; game UI chrome hidden via `@media print`
