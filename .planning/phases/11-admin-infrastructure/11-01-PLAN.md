# Plan 11-01: Admin Infrastructure

## Objective

Replace the existing ReviewerScreen with a lazy-loaded AdminPanel entry point. Wire a useAdmin hook that validates the passcode against the GAS `getAdminData` endpoint and surfaces candidate data. Add a manual refresh button. Admin code is code-split so candidates never download it during normal gameplay.

## What Changes

| Approach | Skip |
|----------|------|
| Replace ReviewerScreen with lazy-loaded AdminPanel | Wrapping old ReviewerScreen |
| `React.lazy` + `<Suspense>` for code splitting | Eager import in App.jsx |
| useAdmin hook owns all admin state | Inline fetch in component |
| Passcode validated via GAS POST (server-side) | Hardcoded passcode in client |
| New `SCREENS.ADMIN` in enum | Overloading SCREENS.REVIEWER |
| Collapsible data panels for progressive disclosure | Flat dump of all data |
| Loading/error/empty states handled | Silent failures |
| Retain ReviewerScreen file as deprecated reference | Delete immediately |

### T02: Build useAdmin hook

**Files:** `src/hooks/useAdmin.js` (NEW)

Create a custom hook that owns all admin state:

```js
// State shape
{
  data: null,           // { candidates, rawData, socData } | null
  loading: false,       // fetch in progress
  error: null,          // string | null
  authenticated: false, // passcode validated successfully
}
```

Actions:
- `fetchAdminData(passcode)` — POST to `LEADERBOARD_URL` with `{ action: "getAdminData", passcode }`. Handle: success (set data + authenticated), unauthorized (set error), network failure (set error).
- `refresh()` — re-fetch with stored passcode if authenticated.
- `reset()` — clear all state (on logout/back).

Import `LEADERBOARD_URL` from `src/config.js`. Use the existing `fetch()` POST pattern from `submitToSheet` in useGameState.js (JSON body, no custom headers for simple CORS).

**Edge cases:**
- Empty data arrays: show empty state, not error
- Network timeout: show "Network error — check connection" 
- Malformed JSON response: show "Unexpected server response"
- Passcode rejected: show "Invalid passcode"

**Verification:** Import hook, call `fetchAdminData('wrong')` → error state. Call with correct passcode → data populated.

### T03: Build AdminPanel component

**Files:** `src/components/AdminPanel.jsx` (NEW)

Build the admin dashboard with three collapsible data sections:

**Props:** `{ onBack }` (PropTypes: `onBack: PropTypes.func.isRequired`)

**States:**
1. **Passcode gate** (initial): Text input + "Access Admin Panel" button. Calls `fetchAdminData(passcode)`.
2. **Loading**: Spinner while fetching.
3. **Error**: Error message with "Try again" button.
4. **Data view** (authenticated): Three collapsible panels + refresh button + back button.

**Data panels:**
- **Candidates** (from `data.candidates`): Table showing name, email, score, grade, date
- **Raw Classifications** (from `data.rawData`): Zone 1-3 classification answers
- **SOC Answers** (from `data.socData`): Zone 4 SPL queries and explanations

**Layout:**
```
┌─────────────────────────────────┐
│  Admin Panel    [Refresh] [Back]│
├─────────────────────────────────┤
│  ▼ Candidates (N)               │
│  ┌─────────────────────────────┐│
│  │ Name │ Email │ Score │ ...  ││
│  ├──────┼───────┼───────┼──────┤│
│  │ ...  │ ...   │ ...   │ ...  ││
│  └─────────────────────────────┘│
│  ▶ Raw Classifications (N)      │
│  ▶ SOC Answers (N)              │
└─────────────────────────────────┘
```

Each panel toggles open/closed on header click. Count badge shows row count.

**Verification:** Component renders passcode gate → enter passcode → data panels appear → click panel header toggles open/close → refresh re-fetches → back returns to landing.

## Threat Model

| Threat | Mitigation |
|--------|-----------|
| Passcode exposed in client bundle | Passcode never stored client-side; validated server-side via GAS `checkPasscode()` against `PropertiesService` |
| Admin chunk loads for candidates | `React.lazy` splits code; chunk only loads on admin button click |
| Network sniffing reveals passcode | Passcode travels in POST body over HTTPS (GAS web app URL is HTTPS) |
| Refresh leaks data to wrong user | Refresh re-validates passcode via stored credential in hook state; resets on back |
| XSS in candidate data | React's JSX escaping handles text content; table renders as text nodes, not dangerouslySetInnerHTML |
