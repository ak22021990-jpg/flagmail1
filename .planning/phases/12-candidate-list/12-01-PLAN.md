## Task 1: Create CandidateList.jsx

### File: `src/components/CandidateList.jsx`

Extract the candidate table from AdminPanel.jsx into a new standalone component with these additions:

**Data access pattern** (from existing AdminPanel lines 210-218):
- `c[0] || c.name` → Name
- `c[1] || c.email` → Email
- `c[6] || c.totalScore || c.score` → Total Score
- `c[7] || c.grade` → Grade Band
- `c[2] || c.date || c.timestamp` → Submission Date
- `c[8] || c.tabSwitches || c.proctoring || c.tabSwitchCount || 0` → Proctoring violations

**Component signature:**
```js
CandidateList({ candidates })  // candidates: array from useAdmin
```

**Features to implement:**

1. **Search (CAND-02):**
   - Text input above the table with placeholder "Search candidates..."
   - Filters rows where name or email contains the search string (case-insensitive `toLowerCase().includes()`)
   - Filtering is instant via `useMemo` — no debounce, no submit button
   - When search is empty, show all candidates

2. **Sort (CAND-03):**
   - Clickable column headers for: Score, Grade, Date
   - State: `{ sortKey, sortDir }` where `sortKey` is `null | "score" | "grade" | "date"`, `sortDir` is `"asc" | "desc"`
   - Clicking a header: if same key, toggle direction; if different key, set to that key with "desc" default
   - Sort indicators: ▲ / ▼ arrows next to active sort column header text
   - Inactive sortable columns show no arrow (Name, Email, Proctoring are not sortable)
   - Grade sort order: "strong" > "good" > "needs improvement" > "not ready" (custom order, not alphabetical)
   - Date sort: parse as string comparison (dates are ISO/string format from Sheets)
   - Score sort: numeric comparison

3. **Grade-band filter (CAND-04):**
   - Filter chips/buttons row between search input and table
   - Options: All (default), Strong, Good, Needs improvement, Not ready
   - Active filter has highlighted style (filled background); inactive filters are outline style
   - Only one filter active at a time (exclusive selection)
   - Clicking the active filter deselects it (returns to "All")

4. **Proctoring column (CAND-05):**
   - New column "Proctoring" in table header
   - Display: tab-switch count as a number
   - Candidates with count > 0: show count in red with a flag indicator (⚠ icon or red background)
   - Candidates with count === 0 or undefined: show "—" in muted color

5. **Empty state:**
   - When no candidates after filtering: "No candidates match your search or filter."
   - When no candidates at all: "No candidates yet."

**Styling rules:**
- Use inline style objects (match AdminPanel.jsx pattern)
- Reuse `gradeColor()` function from AdminPanel (or import it)
- Use `glass` token from `src/styles/tokens.js` for the container
- Follow existing table cell styles: `cellTh` for headers, `cellTd` for data cells
- Framer Motion: use `motion.button` for filter chips with `whileHover`/`whileTap`

**PropTypes:**
```js
CandidateList.propTypes = {
  candidates: PropTypes.array.isRequired,
};
```

**Exports:** Default export.
